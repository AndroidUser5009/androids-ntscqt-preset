
# Android's ntscQT preset
I made this preset for [JargeZ's ntscQT](https://github.com/JargeZ/vhs) application, based on the Master Nama preset. Make sure you set the render height to 1440 for the best results.

## How to use

 1. First, you click the links on the tables shown above.
 2. Then, you click the Raw button.
 3. Press Ctrl+A [select all text] and Ctrl+C [copy text]
 4. Open the ntscQT application and click "Import / Export preset".
 5. Press [Ctrl+V] to paste the text on the text-box on the window that appears.
 6. Click "Save as" and you are done! :slightly_smiling_face:
